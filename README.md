# Kaweewat Chatchawanchaowiwat — Portfolio

Single-page portfolio site for a marketing professional who builds AI agent systems.

**Live**: https://no-project000.github.io/No-Portfolio/

## Featured

**AI Marketing OS** — 13 specialist AI agents covering ~85% of digital marketing
disciplines, coordinated through a single orchestrator with an Opus 4.7 governance
layer. Built solo in Python with Claude Code + MCP integrations across Notion,
Motion, Supermetrics, Adobe, Meta Ads, Google Workspace, Telegram, and LINE OA.

## Tech

- Single `index.html` — vanilla JS, no build step
- Lenis (smooth scroll) + GSAP + ScrollTrigger via CDN
- OKLCH color system, Inter Tight + Inter + JetBrains Mono
- View Transitions API where supported
- Respects `prefers-reduced-motion`
- Deployed via GitHub Pages
